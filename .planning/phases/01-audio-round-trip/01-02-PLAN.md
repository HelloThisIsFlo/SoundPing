## Phase Goal

**As a** musician (or the AI agent I tell to run tests), **I want to** measure my audio round trip from the `soundping` CLI, **so that** I get a trustworthy, saved number on the engine every later recipe reuses.

<objective>
Build the Walking Skeleton: one command, `soundping run round-trip --simulate --json`, goes through every layer (CLI → RunCoordinator → simulated backend on virtual time → chirp matched filter → stats → run store) and returns the injected latency as a saved run.json; CI runs it on every push. Then harden the store and the Codable contract so three plans can build on it in parallel.

Purpose: proves the architecture end to end on the agent's best context before any hardware or DSP depth (01-SKELETON.md). Freezes the contract that plans 01-03, 01-04 and 01-05 consume in parallel in wave 3.
Output: the engine core, the `run` and `runs` commands, `--json`, ci-sim.sh in CI, four test suites.
</objective>
