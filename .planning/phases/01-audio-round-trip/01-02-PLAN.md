## Phase Goal

**As a** musician (or the AI agent I tell to run tests), **I want to** measure my audio round trip from the `soundping` CLI, **so that** I get a trustworthy, saved number on the engine every later recipe reuses.

<objective>
Build the Walking Skeleton: one command, `soundping run round-trip --simulate --json`, goes through every layer (CLI → RunCoordinator → simulated backend on virtual time → chirp matched filter → stats → run store) and returns the injected latency as a saved run.json (Task 1, the tracer, 15 files). Then expand it into the full run surface with CI running it on every push (Task 2). Labels, tags, collision-safe folders, the run lock, `runs list/show` and the contract tests live in plan 01-10 (wave 3), split out so this plan stays inside one executor's context budget.

Purpose: proves the architecture end to end on the agent's best context before any hardware or DSP depth (01-SKELETON.md). Freezes the contract that plans 01-04 and 01-10 consume in parallel in wave 3, then plans 01-03 and 01-05 in wave 4.
Output: the engine core, the `run` command, `--json`, ci-sim.sh in CI, SimulationRecoveryTests.
</objective>
