## Phase Goal

**As a** musician (or the AI agent I tell to run tests), **I want to** measure my audio round trip from the `soundping` CLI, **so that** I get a trustworthy, saved number on the engine every later recipe reuses.

<objective>
Run the round trip on real hardware: a raw CoreAudio HAL IOProc per device plays chirps at exact sample positions and captures them back, with SoundPing's own buffer size, real timestamps feeding the clock model from plan 01-06, and a named abort when a device changes under the run (CAL-01, ENG-07).

Purpose: this is where the HAL timestamp edge and real-time safety get proven on Flo's Scarlett (STATE blockers). Real-time code must never lock or allocate (STACK "What NOT to use").
Output: HALBackend + RTState + IOCycle, device listeners, `--buffer`, simulated device faults, IOCycle/Abort/hardware tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HAL real-time thread ↔ engine | lock-free handoff of audio, stamps and schedule between the IOProc and Swift concurrency |
| SoundPing ↔ the user's audio devices | SoundPing opens devices other apps (the DAW) are using |
| HAL property notifications → engine | asynchronous device changes from drivers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-23 | Denial of service | IOProc (priority inversion, dropped buffers) | high | mitigate | `@_noLocks` on all IOProc code, preallocated rings, Atomic indices; build fails on lock/alloc diagnostics |
| T-01-24 | Tampering | ring buffer bounds | high | mitigate | capacities validated before AudioDeviceStart; index math modulo capacity; IOCycleTests cover wrap and gaps |
| T-01-25 | Tampering | user's device configuration | high | mitigate | never set nominal sample rate, volume, mute or defaults; only the per-process buffer; acceptance greps for SetPropertyData on the rate |
| T-01-26 | Tampering (integrity of results) | device change mid-run | high | mitigate | listeners + gap flag → abort (deviceChanged, exit 75) or rejected hits; AbortTests |
| T-01-SC | Tampering | SwiftPM installs | high | mitigate | no new packages (Synchronization is stdlib) |
</threat_model>
