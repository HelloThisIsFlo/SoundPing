## Phase Goal

**As a** musician (or the AI agent I tell to run tests), **I want to** measure my audio round trip from the `soundping` CLI, **so that** I get a trustworthy, saved number on the engine every later recipe reuses.

<objective>
Make detection and statistics trustworthy: broken hits are rejected with a named reason and counted (never silently dropped, never turned into wrong numbers), the matched filter is sub-sample accurate, robust to reflections and polarity, and the stats match numpy exactly so offline cross-checks agree.

Purpose: CAL-01's 1-2 sample repeatability and RES-01's honest stats rest on this. D-12/D-13 settle the detector design; D-15 asks for an up/down chirp pair Phase 2 can reuse.
Output: hardened Correlator, template library, numpy-matched Stats, simulation knobs for missed hits / xruns / gain, three test suites.
</objective>
