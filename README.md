# SoundPing

Measure the real keypress-to-sound latency of a music setup.

SoundPing presses keys on the Mac keyboard, which Ableton picks up as MIDI notes. It then listens through the MacBook's built-in microphone and records when the sound actually arrives. The gap between the two is the latency you hear when you play.
